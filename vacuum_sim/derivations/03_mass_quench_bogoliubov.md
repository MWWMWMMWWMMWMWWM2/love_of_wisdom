# 03 — Particle creation by a time-dependent mass (Bogoliubov transformation)

Reference: Birrell & Davies, *Quantum Fields in Curved Space*, §3.4; any QFT text on
"parametric excitation".  The same mathematics describes cosmological particle creation
(the mass term is replaced by the scale factor) and the dynamical Casimir effect.

## Mode functions

A mode with frequency ω(t) obeys  f̈ + ω(t)² f = 0.  Start in the vacuum of ω₀ = ω(0):
f(0) = 1/√(2ω₀), ḟ(0) = −iω₀ f(0).  At any later time decompose in the instantaneous basis,

    f = (α e^{−iωt} + β e^{+iωt}) / √(2ω),

    α e^{−iωt} = √(ω/2) ( f + i ḟ/ω ),     β e^{+iωt} = √(ω/2) ( f − i ḟ/ω ),   |α|² − |β|² = 1.

The number of quanta in the mode, relative to the vacuum of the instantaneous ω, is n = |β|².

## In terms of the covariance we propagate

The ensemble covariance of the mode (⟨|Q|²⟩ = C_qq, ⟨|P|²⟩ = C_pp) evolves with the same linear
map as (f, ḟ).  Writing C_qq = |f|², C_pp = |ḟ|² for the state generated from the vacuum,

    C_pp + ω² C_qq = ω ( |α|² + |β|² ) = ω ( 2|β|² + 1 )
    ⇒  n = (C_pp + ω² C_qq)/(2ω) − ½ ,                                                   (eq. F1 of field.py)

exact for any Gaussian state generated by linear evolution from the vacuum.

## Sudden quench ω₀ → ω₁

f and ḟ are continuous, so with f = 1/√(2ω₀), ḟ = −iω₀ f:

    |β|² = (ω/2) |f − iḟ/ω|² = (ω₁/2) (1/(2ω₀)) (1 − ω₀/ω₁)²  =  (ω₁ − ω₀)² / (4 ω₀ ω₁).

Checked to 1e-12 in `test_sudden_quench_bogoliubov`, and the created energy density
(1/V) Σ_k ω₁ n_k agrees with the statistical mean of the sample's excess energy.

Physically: a field whose mass changes suddenly (a modulus / Higgs-like background jumping to a
new value; the "reheating"-type creation) turns vacuum fluctuations into real quanta,
predominantly at low k where (ω₁ − ω₀)²/ω₀ω₁ is largest.  The button "Quench now" with ramp
duration 0 does exactly this; the read-out compares the tracked n_k with the formula.

## Adiabatic ramp

If ω changes slowly, |ω̇| ≪ ω², the WKB solution f ≈ e^{−i∫ω dt}/√(2ω) stays a positive-frequency
solution and |β|² is exponentially small (∼ e^{−c ω τ}).  `test_adiabatic_ramp_creates_fewer_particles`
checks that a ramp over 12 l_s/c creates < 1/20 of the particles of a sudden quench between the
same masses.  In the GUI: increase "ramp duration" and watch the created-particle read-out drop —
this is the adiabatic theorem made visible.

## What is shown in 3D

After a quench the *sample* contains real particles, but a single history cannot separate them
from the vacuum fluctuations point by point (the vacuum has no particles yet a non-zero field).
Rendering "excess over vacuum", h(x,t) − ⟨h⟩_vac(z), shows a field whose *spatial mean* is the
particle energy density (positive), riding on the ± vacuum noise.  The exact number is in the
panel and in the history plot.
